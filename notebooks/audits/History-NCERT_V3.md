# Audit: "1. History-NCERT_V3.pdf"

**Source:** Unacademy, *NCERT Simplified — History (Class VI–XII)*, July 2026 edition, 597 pages. Copyrighted; we use it only as a reference. Facts are verified and rewritten in our own words, never copied.

**Method, per chapter:**
1. Read the notes; skip the summary and the publisher's MCQs.
2. Check what our units already cover.
3. Verify anything new.
4. Add in-syllabus material to the mapped unit.
5. Log the errors found.

PDF page = book page + 3.
